# 1 / QUADRILLION : IMPERIALIS VITA

Warhammer 40,000 인류제국 세계관을 배경으로 한 **로컬 / 정적 웹 기반 인생 시뮬레이션 게임**입니다. (Unofficial Fan Project)

《80억 분의 1》의 무작위 출생·생애 시뮬레이션 감성에 워해머 40,000 공식 TRPG(《Dark Heresy》, 《Imperium Maledictum》)의 **8대 특성치(d100 판정)**, **병종·승급 트리**, **M41~M42 실제 역사 대사건 & 네임드 인물 조우**를 결합했습니다.

## 실행 방법

* **로컬 바로 실행:** 별도 서버나 설치 없이 `index.html` 파일을 웹 브라우저로 열면 즉시 실행됩니다.
* **GitHub Pages 배포:** 이 폴더 전체를 GitHub 저장소에 푸시한 뒤, `Settings → Pages → Deploy from a branch (main / root)`를 선택하면 별도 빌드 없이 정적 사이트로 배포됩니다.

## 주요 시스템

1. **운명 모드 vs 지정 출생 모드**
   * **운명 모드:** 제국 인구 가중치에 따라 22종의 행성(테라, 화성, 카디아, 크리그, 아마겟돈, 네크로문다, 마크라그, 바알, 펜리스, 카타찬, 보스트로야, 발할라, 타니스, 녹턴, 오펠리아 VII + 일반 7유형), 출생 신분 10종, 선천 자질 8종이 무작위로 결정됩니다.
   * **지정 출생 모드:** 시대 구간, 행성, 신분, 자질, 성별, 이름을 직접 선택해 원하는 빌드와 역사 사건을 플레이할 수 있습니다.
2. **워해머 40k 고증 8대 특성치 & d100 판정**
   * `WS(백병)`, `BS(사격)`, `T(강인)`, `Ag(민첩)`, `Int(지성)`, `WP(의지)`, `Fel(교섭)`, `Inf(권위)` + `생명력(Wounds)`, `신앙(Faith)`, `오염(Corruption)`.
   * 연간 **삶의 초점(Focus)** 관리와 선택지 결과를 통해 스탯을 육성하면 숨겨진 이벤트, 잠긴 선택지, 상위 병종이 동적으로 해금됩니다.
3. **17개 세력 78종 풀 계급·직군 트리 · 이벤트 기반 진로 제안 · 평행 횡단**
   * 시민/길드/언더하이브, 아스트라 밀리타룸(보병·분대장·장교·장군·워마스터·로드 커맨더 밀리탄트), 커미사르(생도→총커미사르), 아뎁타 소로리타스(노비티에이트→아베스 상크토룸), 국교회(사제→에클레시아크), 아스타르테스(네오파이트→분대장→1중대 터미네이터→캡틴→챕터 마스터), 그레이 나이트(팔라딘→슈프림 그랜드 마스터), 아뎁투스 쿠스토데스(워든→실드-캡틴→캡틴-제너럴), 이단심문소(어콜라이트→심문자→이단심문관→로드 이단심문관→테라 대표), 메카니쿠스(스키타리/마셜·테크프리스트→파브리케이터-제너럴), 임페리얼 네이비, 아르비테스, 아드미니스트라툼, 행성 총독→섹터 로드 공훈 횡단 루트, 로그 트레이더 가문(세네샬→로그 트레이더→로드 캡틴), 공인 사이커(프리마리스→총관), 그리고 필멸자 카오스 컬트 vs 배신자 아스타르테스(CSM)·카오스 로드 분리 및 **데몬 프린스 승천**까지 총 **78종 선택 직군**(테라의 하이 로드 10석 포함)을 수록했습니다.
   * 상위 계급·공훈 횡단·최고위 추대는 조건 달성 시 **동적 발탁·임명 이벤트**로 자연스럽게 제안되며, 모든 직군에 계급별 자율 행동(4년 재사용)과 전용 분기·연대기가 연동됩니다.
4. **9대 아스타르테스 챕터 서약 & 고유 서사**
   * 스페이스 마린 네오파이트로 입단하면 울트라마린, 블러드 엔젤, 스페이스 울프, 다크 엔젤, 임페리얼 피스트, 샐러맨더, 블랙 템플러(사이커 입단 불가), 레이븐 가드, 화이트 스카 중 챕터를 선택해 전투 함성과 챕터 고유 이벤트(붉은 갈증, 폴른 사냥, 황제의 투사 등)를 경험합니다.
5. **M41~M42 시기·장소 전용 사건 & 네임드 인물 스포트라이트**
   * 사바트 월드 성전, 바답 전쟁, 제2·3차 아마겟돈 전쟁, 카디아 붕괴, 영원한 밤(Noctis Aeterna), 테라 육두정치 쿠데타, 파리아 넥서스의 정적, 라이온의 보호령 등 **특정 시대와 장소에서만 열리는 전용 사건**을 수록했습니다.
   * 길리먼, 야릭, 케인, 앰벌리 베일, 건트, 단테, 카울, 셀레스틴, 아이젠혼, 로간 그림나르, 투샨, 그리말두스, 아즈라엘, 트라얀 발로리스, 라이온 엘 존슨 등 **20인 네임드 인물**을 조우하면 사건 창 상단에 인물 소개 스포트라이트 카드가 펼쳐지며 전용 서사가 전개됩니다.
   * 상단 **`제국 코덱스`** 탭에서 모든 행성·17개 세력별 계급도·챕터·연표·인물 데이터와 공식 참조 출처(Lexicanum 링크 포함)를 직접 대조할 수 있습니다.
6. **529종 연대기 · 432종 분기/역사 사건 · 자동 저장 · 기록 내보내기 · 영혼의 전당 도감**
   * 전선·환경·비전투 루트 전용 치명적 위기 사건(24종), 6대 연대·아스타르테스 4대 전문 직책 분기, 행성별 유년기 연대기를 포함해 총 **529종 연대기** 및 **432종 분기·역사 사건**을 수록했습니다.
   * 진행 중인 생애는 브라우저 `localStorage`에 자동 저장되어 새로고침 후에도 이어할 수 있으며, `유년기 빠른 진행`·`새 진로 해금 시 알림·일시정지`·`새 기록 자동 알림` 편의 옵션을 지원합니다.
   * **`전체 인생 기록서`**와 사망 부고 창에서 거쳐 온 계급 궤적과 생애 전문을 순수 텍스트로 복사하거나 `.txt` 파일로 저장할 수 있으며, **`영혼의 전당`**에서 전체 도감 수집률(78종 직군 누적 이력 포함)·미수집 해금 힌트·과거 영혼의 상세 조서를 열람할 수 있습니다.

## 데이터 확장 방법 및 개발 문서

`data/` 디렉토리의 코어 정의 파일(`worlds.js`, `origins.js`, `careers.js`, `chapters.js`, `characters.js`, `timeline.js`, `tags.js`)과 도메인별 계층 폴더(`data/events/{careers,chapters,worlds,themes}/`, `data/chronicles/`)에 항목이나 새 파일을 추가하면 엔진이 자동으로 인식해 게임과 코덱스에 반영합니다.
특히 `data/chronicles/`는 행성·직업·신분·나이·시대 조건을 엄격히 대조해 본인 상황에 맞는 인류제국 일상 및 부조리 연대기 로그를 자동 출력합니다.
새 데이터 파일을 추가한 뒤에는 `node scripts/sync-scripts.js`로 `index.html`의 스크립트 목록을 자동 동기화하고, `node scripts/qa.js`를 실행해 구문·고아 파일·DOM 무결성·고증 표기·소프트락·300생애 시뮬레이션 6대 QA 게이트를 한 번에 검증할 수 있습니다.

전체 아키텍처, 파일별 수록 현황, 엔진 스키마 및 단계별 진행 보고서는 [`PROJECT_GUIDE.md`](./PROJECT_GUIDE.md)를, AI 에이전트 작업 방향, 접근성·고증·나무위키 표기 불변 규칙 및 QA 게이트는 [`AGENTS.md`](./AGENTS.md)를 참고하십시오.
