# 1 / QUADRILLION : IMPERIALIS VITA

Warhammer 40,000 인류제국 세계관을 배경으로 한 **Astro + React 아일랜드 기반 정적 웹 인생 시뮬레이션 게임 · 워해머 40k 개념 사전 · 제국 코덱스**입니다. (Unofficial Fan Project)

《80억 분의 1》의 무작위 출생·생애 시뮬레이션 감성에 워해머 40,000 공식 TRPG(《Dark Heresy》, 《Imperium Maledictum》)의 **8대 특성치(d100 판정)**, **21개 세력 91종 병종·승급 트리**, **M41~M42 29대 역사 대사건 & 28인 네임드 인물 조우**, 그리고 입문자도 부담 없이 세계관을 탐색할 수 있는 **48종 워해머 40k 개념 사전**을 결합했습니다.

## 실행 및 배포 방법

* **GitHub Pages 자동 배포 (권장):**
  * 퍼블릭 저장소 `Settings` > `Pages` > `Build and deployment` > `Source`를 **`GitHub Actions`**로 한 번만 설정하면, `main` 브랜치에 푸시할 때마다 `.github/workflows/deploy.yml`이 자동 검증(`qa.mjs` · `audit-health.mjs` · `npm test` · `npm run build`) 후 `https://pong3147.github.io/warhammer/`에 배포합니다.
* **로컬 개발 · 미리보기 · 전체 검증 (Node.js 22.23.4+):**
  * 의존성 설치: `npm install`
  * 개발 서버: `npm run dev`
  * 정적 빌드 및 미리보기: `npm run build && npm run preview`
  * 타입 검사: `npm run typecheck` (`astro sync && tsc --noEmit`)
  * 전체 검증 게이트: `npm run verify` (`qa` + `audit` + `typecheck` + `test` + `build` + `qa:dist`)
  * 심층 7대 게이트 검증: `npm run qa:deep` (`node scripts/qa.mjs --deep`)
  * 콘텐츠 밀도 매트릭스: `node scripts/coverage-report.mjs`

## 페이지 구성 (Astro SSG + React Islands)

정적 페이지(`/glossary/`, `/codex/**`, `/hall/`)는 빌드 타임에 순수 HTML로 생성되며 2MB급 생애 사건·연대기 번들(`narrative.js`)을 전혀 로드하지 않아 빠르고 가볍게 열람할 수 있습니다.

1. **생애 시뮬레이션 (`/`)** — 인터랙티브 React 아일랜드 (코어 메타데이터 선로드 + 사건·연대기 비동기 지연 로드)
   * 기본 1배속 `1년 = 60초`(분기당 20.0초)부터 **2배속(30초/년), 4배속(15초/년), 8배속(7.5초/년), 16배속(3.75초/년)**까지 5단계 배속을 지원합니다.
2. **워해머 40k 개념 사전 (`/glossary/`)** — 8대 카테고리 · 48종 핵심 용어 정적 해설서
   * 인류제국의 기둥, 워프·사이커·카오스, 군대와 초인 기관, 기계교·심문소·행정, 행성 분류와 인류 사회, 주요 외계 종족, 제국 연대기와 M41~M42 대전환, 게임 시스템 용어를 자체 작성한 한국어 산문과 코덱스 상호 링크로 제공합니다.
3. **제국 코덱스 (`/codex/`)** — 5대 정적 도감 (`/codex/worlds/`, `/codex/careers/`, `/codex/chapters/`, `/codex/timeline/`, `/codex/characters/`)
   * 23개 행성, 21개 세력 91종 계급도, 9대 아스타르테스 챕터, 29대 M41~M42 역사 연표, 28인 네임드 인물과 Lexicanum 참조 출처를 검색·필터링할 수 있습니다.
4. **영혼의 전당 (`/hall/`)** — 과거 생애 기록 · 91종 직군 누적 도감 수집률 · `.json` 저장본 백업 내보내기/불러오기

## 주요 시스템

1. **운명 모드 vs 지정 출생 모드**
   * **운명 모드:** 제국 인구 가중치에 따라 23종의 행성(테라, 화성, 카디아, 크리그, 아마겟돈, 네크로문다, 마크라그, 바알, 펜리스, 카타찬, 보스트로야, 발할라, 타니스, 녹턴, 오펠리아 VII + 기사 행성 및 일반/보이드본 8유형), 출생 신분 11종, 선천 자질 8종이 무작위로 결정됩니다.
   * **지정 출생 모드:** 9개 시대 구간(고딕 전쟁기·아이젠혼 시대·제1차 아마겟돈과 수치의 달들·사바트 성전기·바답 전쟁기·제2·3차 아마겟돈·카디아 붕괴·인도미투스 성전 등), 행성, 신분, 자질, 성별, 이름을 직접 선택해 원하는 빌드와 역사 사건을 플레이할 수 있습니다.
2. **워해머 40k 고증 8대 특성치 · d100 판정 · 3대 도덕 성향 (`자비 · 교조 · 암흑`)**
   * 백병(WS), 사격(BS), 강인(T), 민첩(Ag), 지성(Int), 의지(WP), 교섭(Fel), 권위(Inf)와 생명력, 황제 신앙, 워프 오염, 그리고 독립 누적 **3대 도덕 성향**(`자비·인본`, `교조·광신`, `암흑·탐욕`)을 지원합니다.
   * 연간 **삶의 초점(Focus)** 관리와 선택지 결과를 통해 스탯과 성향을 육성하면 성향 우대(`alignBias`)·전용 사건, 잠긴 선택지, 상위 병종 지름길과 맞춤 부고가 동적으로 열립니다.
3. **21개 세력 91종 풀 계급·직군 트리(테라의 하이 로드 12석 완비) · 이벤트 기반 진로 제안 · 평행 횡단**
   * 시민/길드/언더하이브, 아스트라 밀리타룸(보병·분대장·장교·장군·워마스터·로드 커맨더 밀리탄트), 커미사르(생도에서 총커미사르), 아뎁타 소로리타스(노비티에이트에서 아베스 상크토룸), 국교회(사제에서 에클레시아크), 아스타르테스(네오파이트에서 챕터 마스터·드레드노트), 그레이 나이트(팔라딘에서 슈프림 그랜드 마스터), 아뎁투스 쿠스토데스(워든에서 캡틴-제너럴), 이단심문소(어콜라이트에서 테라 대표), 메카니쿠스(스키타리/마셜·테크프리스트에서 파브리케이터-제너럴), 임페리얼 네이비, 아르비테스, 아드미니스트라툼, 행성 총독에서 섹터 로드 공훈 횡단, 로그 트레이더 가문, 공인 사이커, 나비스 노빌리테(항법사에서 파테르노발 특사), 오피시오 아사시노룸(4대 템플에서 암살청 총수), 임페리얼 나이트(종자에서 하이 킹/하이 퀸), 살아 있는 성인(리빙 세인트 · 자비/심판 위상 분기), 그리고 필멸자 카오스 컬트·배신자 아스타르테스(CSM)·카오스 로드·데몬 프린스 승천까지 총 **91종 선택 직군**을 수록했습니다.
   * 비구속 민간·초년에서 정규 서약 기관으로 첫 입단 시 비치명적 d100 입단 심사 및 2년 최소 복무·재지원 대기가 적용되며, 상위 계급·타 기관 특별 초빙(스카우트)·공훈 횡단·최고위 추대는 조건 달성 시 **동적 발탁·임명 이벤트**로 자연스럽게 제안됩니다. 모든 직군에 계급별 자율 행동(4년 재사용), 행성 출입 자격·강제 파견 체계, 억지 하락 없는 수확 체감 스탯 성장과 투명한 d100 상황 판정(`5%~90%` 상한)이 연동됩니다.
4. **9대 아스타르테스 챕터 서약 & 고유 서사**
   * 스페이스 마린 네오파이트로 입단하면 울트라마린, 블러드 엔젤, 스페이스 울프, 다크 엔젤, 임페리얼 피스트, 샐러맨더, 블랙 템플러(사이커 입단 불가), 레이븐 가드, 화이트 스카 중 챕터를 선택해 전투 함성과 챕터 고유 이벤트(붉은 갈증, 폴른 사냥, 황제의 투사 등)를 경험합니다.
5. **M41~M42 29대 역사 대사건 · 28인 네임드 스포트라이트 & 정사 크로스오버**
   * 고딕 전쟁(제12차 블랙 크루세이드), 마카리우스 대성전, 제1차 아마겟돈 전쟁과 수치의 달들, 사바트 월드 성전, 바답 전쟁, 제2·3차 아마겟돈 전쟁, 제3차 타이라니드 전쟁(크립트만의 방화선), 카디아 붕괴, 대균열과 영원한 밤, 옥타리우스 전쟁, 울트라마 역병 전쟁, 파리아 넥서스, 징조의 방주와 라이온 귀환, 제4차 타이라니드 전쟁 등 **29대 M41~M42 역사 대사건**과 28인 네임드 인물의 단독 조우·정사 크로스오버·후일담 연대기를 제공합니다.
6. **705종 분기/역사 사건 · 796종 연대기 · 스크린 리더 접근성 · 자동 저장/백업**
   * 진행 중인 생애는 브라우저 `localStorage`에 자동 저장되며(기존 저장 키 100% 하위 호환, `.json` 백업 내보내기/불러오기 지원), `현재 상태 요약 듣기`·`다음 사건까지 진행`·`초장수 자발적 명예 마감`·`유년기 빠른 진행`·`새 진로 해금 시 알림·일시정지`·`새 기록 자동 알림` 등 시각장애인 스크린 리더 친화 기능을 제공합니다.
   * **`전체 인생 기록서`**와 사망 부고 창에서 도덕 성향·거쳐 온 계급 궤적·생애 전문을 순수 텍스트로 복사하거나 `.txt` 파일로 저장할 수 있습니다.

## 데이터 확장 방법 및 개발 문서

`src/data/core/`의 코어 정의 파일(`worlds.js`, `origins.js`, `careers.js` + `careers/{civil_militarum,faith_shadow,transhuman_chaos,specialist_factions}.js`, `chapters.js`, `characters.js`, `timeline.js` + `timeline/{m41_early,m41_late,m42_indomitus}.js`, `tags.js`), 개념 사전 `src/data/glossary.js`, 그리고 도메인별 계층 폴더(`src/data/events/{careers,chapters,worlds,themes}/`, `src/data/chronicles/`)에 ESM 모듈(`export default [...]`)로 항목이나 새 파일을 추가하면 Astro 빌드, `import.meta.glob`, Node.js QA 스위트가 자동으로 인식합니다.

변경 후에는 `npm run verify` 또는 `npm run qa:deep`을 실행해 7대 QA 게이트, 200생애 무작위 퍼징, Vitest 행동형 접근성 테스트, 정적 빌드를 한 번에 검증할 수 있습니다.

전체 아키텍처, 파일별 수록 현황, 엔진 스키마 및 단계별 진행 보고서는 [`PROJECT_GUIDE.md`](./PROJECT_GUIDE.md)를, AI 에이전트 작업 방향, 접근성·고증·나무위키 표기 불변 규칙 및 QA 게이트는 [`AGENTS.md`](./AGENTS.md)를 참고하십시오.
